# Отчёт по задаче 36

## Идея решения и выбор структуры данных

Исходные числа хранятся в массиве `int[]`. Для ответа создаётся массив `long[]` такой же
длины, потому что по условию нужно вывести новый массив. Программа идёт слева направо,
добавляет текущее число к сумме и записывает эту сумму в ответ.

## Асимптотика

- Время работы — `O(n)`, потому что каждый элемент обрабатывается один раз.
- Дополнительная память — `O(n)`, потому что создаётся новый массив из `n` элементов.

## Ручные тесты

1. `[1, 2, 3, 4]` → `[1, 3, 6, 10]`. Проверяет обычный случай.
2. `[5, -2, -4, 3]` → `[5, 3, -1, 2]`. Проверяет положительные и отрицательные числа.
3. `[0, 0, 0]` → `[0, 0, 0]`. Проверяет массив из нулей.
