# Отчёт по лабораторной работе №1

## Задача 1

### Идея решения и выбор структуры данных

Числа хранятся в массиве `int[]`, потому что по условию дан массив целых чисел.
Сначала минимум и максимум равны первому элементу. Затем программа проходит по
остальным элементам. Если найдено меньшее число, меняется минимум. Если найдено
большее число, меняется максимум.

### Асимптотика

- Время работы — `O(n)`, потому что программа один раз проходит по массиву.
- Дополнительная память — `O(1)`, потому что используются только две переменные для
  минимума и максимума. Сам входной массив занимает `O(n)` памяти.

### Ручные тесты

1. `[4, 2, 9, 1, 6]` → `1 9`. Проверяет обычный случай.
2. `[-8, -3, -10, -5]` → `-10 -3`. Проверяет работу с отрицательными числами.
3. `[7, 7, 7]` → `7 7`. Проверяет массив из одинаковых чисел.

## Задача 2

### Идея решения и выбор структуры данных

Числа хранятся в массиве `int[]`. Программа идёт по массиву с начала и сравнивает
каждый элемент с числом `x`. При первом совпадении возвращается индекс элемента.
Если совпадений нет, возвращается `-1`.

### Асимптотика

- Время работы — `O(n)` в худшем случае, потому что иногда нужно проверить весь массив.
- Дополнительная память — `O(1)`, потому что новые массивы не создаются. Входной массив
  занимает `O(n)` памяти.

### Ручные тесты

1. Массив `[4, 7, 2, 7]`, `x = 7` → `1`. Проверяет, что возвращается первое вхождение.
2. Массив `[5, 2, 3]`, `x = 5` → `0`. Проверяет элемент в начале массива.
3. Массив `[1, 2, 3]`, `x = 8` → `-1`. Проверяет случай, когда числа нет в массиве.

## Задача 3

### Идея решения и выбор структуры данных

Числа хранятся в массиве `int[]`. Сначала количество вхождений равно нулю. Программа
проходит по всему массиву и увеличивает количество на один каждый раз, когда встречает
число `x`.

### Асимптотика

- Время работы — `O(n)`, потому что проверяется каждый элемент массива.
- Дополнительная память — `O(1)`, потому что используется одна переменная для количества.
  Входной массив занимает `O(n)` памяти.

### Ручные тесты

1. Массив `[2, 5, 2, 2, 7]`, `x = 2` → `3`. Проверяет несколько вхождений.
2. Массив `[1, 3, 5]`, `x = 2` → `0`. Проверяет случай без вхождений.
3. Массив `[4, 4, 4]`, `x = 4` → `3`. Проверяет случай, когда подходят все элементы.

## Задача 5

### Идея решения и выбор структуры данных

Числа хранятся в массиве `int[]`. Программа начинает с индекса `0` и переходит через
два элемента: `0`, `2`, `4` и так далее. Числа на этих позициях прибавляются к сумме.
Для суммы используется тип `long`, чтобы в неё мог поместиться большой результат.

### Асимптотика

- Время работы — `O(n)`. Программа смотрит примерно половину элементов, но их количество
  всё равно зависит от размера массива `n`.
- Дополнительная память — `O(1)`, потому что используется одна переменная для суммы.
  Входной массив занимает `O(n)` памяти.

### Ручные тесты

1. `[5, 10, 3, 8, 2]` → `10`. Складываются элементы `5`, `3` и `2`.
2. `[-2, 7, -3, 4]` → `-5`. Проверяет работу с отрицательными числами.
3. `[0, 100, 0, 200]` → `0`. Проверяет, что элементы с нечётными индексами не берутся.

## Задача 6

### Идея решения и выбор структуры данных

Числа хранятся в массиве `int[]`. Сначала программа складывает все элементы и делит
сумму на количество элементов. Так получается среднее значение. Затем программа ещё
раз проходит по массиву и считает числа, которые строго больше среднего.

### Асимптотика

- Время работы — `O(n)`, потому что программа два раза проходит по массиву. Два прохода
  всё равно дают `O(n)`.
- Дополнительная память — `O(1)`, потому что используются только сумма, среднее и счётчик.
  Входной массив занимает `O(n)` памяти.

### Ручные тесты

1. `[1, 2, 3, 6]` → `1`. Среднее равно `3`, больше него только число `6`.
2. `[5, 5, 5]` → `0`. Проверяет, что числа, равные среднему, не считаются.
3. `[-6, -2, -1, -3]` → `2`. Проверяет работу с отрицательными числами.

## Задача 9

### Идея решения и выбор структуры данных

Числа хранятся в массиве `int[]`. Начиная со второго элемента, программа сравнивает
каждый элемент с предыдущим. Если следующий элемент меньше предыдущего, массив не
отсортирован. Если таких элементов нет, массив отсортирован по неубыванию.

### Асимптотика

- Время работы — `O(n)` в худшем случае, потому что может потребоваться проверить весь
  массив.
- Дополнительная память — `O(1)`, потому что новые массивы не создаются. Входной массив
  занимает `O(n)` памяти.

### Ручные тесты

1. `[1, 2, 3, 4]` → `YES`. Проверяет массив с возрастающими числами.
2. `[1, 2, 2, 5]` → `YES`. Проверяет, что одинаковые соседние числа разрешены.
3. `[1, 4, 3, 5]` → `NO`. Проверяет нарушение порядка в середине массива.

## Задача 25

### Идея решения и выбор структуры данных

Числа хранятся в массиве `int[]`, потому что по условию дан массив целых чисел.
Сначала сумма равна нулю. Затем программа один раз проходит по массиву и прибавляет

### Ручные тесты

1. `[1, 2, 3, 4]` → `10`. Проверяет обычный случай с положительными числами.
2. `[-5, 10, -3, 2]` → `4`. Проверяет работу с положительными и отрицательными числами.
3. `[0, 0, 0]` → `0`. Проверяет, что нули не изменяют сумму.
4. `[2000000000, 2000000000]` → `4000000000`. Проверяет большую сумму.

## Задача 26

### Идея решения и выбор структуры данных

Числа хранятся в массиве `int[]`. Сначала произведение равно единице. Программа проходит

### Ручные тесты

1. `[2, 3, 4]` → `24`. Проверяет обычное умножение.
2. `[5, 0, 7]` → `0`. Проверяет массив с нулём.
3. `[1000000007, 2]` → `0`. Проверяет взятие остатка от деления.

## Задача 37

2. `[5, -2, 0]` → `[0, -2, 5]`. Проверяет массив нечётной длины.
3. `[7, 7, 7]` → `[7, 7, 7]`. Проверяет массив из одинаковых чисел.

## Задача 49

### Идея решения и выбор структуры данных

Матрица хранится в двумерном массиве `int[][]`. Для ответа создаётся массив `long[]`,
в котором для каждой строки хранится её сумма. Программа проходит по каждой строке,
складывает её элементы и записывает результат в массив ответа.

### Асимптотика

- Время работы — `O(n * m)`, потому что программа просматривает все элементы матрицы
  размером `n` строк на `m` столбцов.
- Дополнительная память — `O(n)`, потому что ответ содержит одну сумму для каждой строки.
  Сама входная матрица занимает `O(n * m)` памяти.

### Ручные тесты

1. `[[1, 2, 3], [4, 5, 6]]` → `[6, 15]`. Проверяет обычную матрицу.
2. `[[-1, 2], [-3, -4]]` → `[1, -7]`. Проверяет отрицательные числа.
3. `[[0, 0], [3, 4]]` → `[0, 7]`. Проверяет строку из нулей.

2. `[[-1, 2], [-3, -4]]` → `[-4, -2]`. Проверяет отрицательные числа.
