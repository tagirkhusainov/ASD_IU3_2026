# Отчёт по задаче 31

## Идея решения и выбор структуры данных

Данные хранятся в двух массивах `int[]`, потому что по условию даны два массива.
Программа умножает элементы с одинаковыми индексами и складывает полученные произведения.
Для результата используется тип `long`.

## Асимптотика

- Время работы — `O(n)`, потому что программа один раз проходит по индексам двух массивов.
- Дополнительная память — `O(1)`, потому что используется одна переменная для результата.
  Два входных массива вместе занимают `O(n)` памяти.

## Ручные тесты

1. `[1, 2, 3]` и `[4, 5, 6]` → `32`. Проверяет обычный случай:
   `1 * 4 + 2 * 5 + 3 * 6 = 32`.
2. `[-1, 2]` и `[3, -4]` → `-11`. Проверяет работу с отрицательными числами.
3. `[0, 0, 0]` и `[4, 5, 6]` → `0`. Проверяет умножение на ноль.
